# Shepherd.Contexts Module

Optimized context storage for LLM efficiency using a fragment-based architecture.

## Purpose

Instead of storing one large JSONB document per entity (the legacy `website_contexts` approach), context is split into small, independent fragments. This allows the LLM to fetch only the fragments it needs, reducing parsing time and token usage.

## Integration Status

**Full CRUD via `Shepherd.Contexts` context module** at `lib/shepherd/contexts.ex`. Provides complete query and mutation operations for context fragments with user scoping, polymorphic entity lookup, and batch operations.

#### Valid Fragment Types

| Fragment Type        | Recommended Access Frequency | Description                                    |
|----------------------|------------------------------|------------------------------------------------|
| `concept`            | `low`                        | High-level understanding (changes rarely)      |
| `active_tasks`       | `high`                       | Current priorities (changes often)             |
| `behavioral_notes`   | `high`                       | User interaction patterns (changes often)      |
| `scan_cache`         | `low`                        | Website scan results (large, changes rarely)   |
| `confusion`          | `medium`                     | Ambiguous information requiring clarification  |
| `short_term_memory`  | `medium`                     | Recent insights and decisions                  |

#### Polymorphic Pattern

This schema uses the **entity_type + entity_id** polymorphic pattern shared across the codebase (also used by `commands`, `user_questions`, and `action_logs`). The `entity_type` column is a string discriminator (e.g., `"website"`) and `entity_id` is a UUID pointing to the owning record. There are no Ecto `belongs_to` associations defined -- the polymorphic lookup is manual.

#### Changeset: `changeset/2`

**Cast fields:** `user_id`, `entity_type`, `entity_id`, `fragment_type`, `content`, `updated_by`, `access_frequency`, `updated_at`

**Validations:**
- `validate_required` -- `[:user_id, :entity_type, :entity_id, :fragment_type, :content]`
- `validate_inclusion(:fragment_type)` -- must be one of: `concept`, `active_tasks`, `behavioral_notes`, `scan_cache`, `confusion`, `short_term_memory`
- `validate_inclusion(:access_frequency)` -- must be one of: `high`, `medium`, `low`
- `validate_inclusion(:updated_by)` -- must be one of: `llm`, `user`, `system`
- `unique_constraint([:entity_type, :entity_id, :fragment_type])` -- enforces one fragment per type per entity (constraint name: `context_fragments_unique`)
- `maybe_set_updated_at/1` -- always sets `updated_at` to `DateTime.utc_now()` truncated to seconds

#### Helper Functions

- `access_frequency_for_type(fragment_type)` -- Returns the recommended access frequency string for a given fragment type. Falls back to `"medium"` for unknown types.
- `should_cache?(fragment)` -- Returns `true` for fragments with `"high"` or `"medium"` access frequency, `false` for `"low"`.
- `size_category(fragment)` -- Returns an atom indicating content size: `:small` (< 1KB), `:medium` (< 10KB), `:large` (< 100KB), `:very_large` (>= 100KB). Uses `:erlang.term_to_binary/1` for size estimation.

## Associations

There are **no Ecto associations** defined in this schema. The relationships are:

- **user_id** -- References `users.id` (integer FK, `on_delete: :delete_all` at the DB level). No `belongs_to` in the schema.
- **entity_type + entity_id** -- Polymorphic reference. No `belongs_to` in the schema. The owning entity (e.g., a `Website`) does not define a `has_many` for context fragments either.

## `Shepherd.Contexts` (Context Module)

Context module providing full CRUD operations for context fragments with user scoping and polymorphic entity support.

#### Functions

- **`get_fragment/3`** -- Retrieves a single context fragment. Params: `(user_id, entity_type, entity_id)` or `(user_id, entity_type, entity_id, fragment_type)`. Returns `{:ok, fragment}` or `{:error, :not_found}`.
- **`get_all_fragments/2`** -- Retrieves all fragments for an entity. Params: `(user_id, entity_type, entity_id)`. Returns list of fragments.
- **`get_fragments_by_frequency/3`** -- Filters fragments by access frequency. Params: `(user_id, entity_type, frequency_level)`. Returns list of fragments.
- **`upsert_fragment/2`** -- Creates or updates a context fragment. Params: `(user_id, attrs)`. Returns `{:ok, fragment}` or `{:error, changeset}`.
- **`update_fragment/3`** -- Updates an existing fragment. Params: `(user_id, fragment_id, updates)`. Returns `{:ok, fragment}` or `{:error, :not_found}`.
- **`delete_fragment/3`** -- Deletes a single fragment. Params: `(user_id, entity_type, fragment_type)`. Returns `{:ok, fragment}` or `{:error, :not_found}`.
- **`delete_all_fragments/2`** -- Deletes all fragments for an entity. Params: `(user_id, entity_type, entity_id)`. Returns count of deleted records.
- **`build_context/2`** -- Assembles all fragments for an entity into a single context map. Params: `(user_id, entity_id)`. Returns merged context map.
- **`fragment_count/2`** -- Returns count of fragments for an entity. Params: `(user_id, entity_type, entity_id)`. Returns integer.
